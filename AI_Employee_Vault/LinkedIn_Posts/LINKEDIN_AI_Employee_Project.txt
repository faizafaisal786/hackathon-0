I built an AI Employee that runs 24/7 on Oracle Cloud Free Tier.

It watches my Gmail inbox, reads every email, and automatically:
- Drafts replies
- Writes LinkedIn posts
- Flags job opportunities
- Tracks action items in Obsidian

The architecture is a Cloud/Local split:
- Cloud agent (always on) handles triage and drafts
- Local agent reviews and approves before anything gets sent

Stack: Groq + Gemini + Python + Obsidian + Oracle Cloud

No subscriptions. No monthly fees. Just free-tier infrastructure doing real work.

Already processed 300+ emails automatically. Built this as a 19-year-old learning AI engineering by shipping real things.
